# Segments — Аура

Раздел **Сегменты** платформы Аура.

Позволяет создавать, просматривать и управлять сегментами клиентов.

## Стек

- React 19 + Vite
- React Router 7
- CSS-переменные дизайн-системы Точки

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```
