# Прототипы

Прототипы для вайбкодинга — **самодостаточные приложения** в отдельных папках.

Скопируй [`_template/`](./_template/) рядом с клонированным `design-system/`:

```text
ai-learning/
  design-system/
  profile-settings/    ← твой прототип
```

Подробнее — в [`_template/README.md`](./_template/README.md).
